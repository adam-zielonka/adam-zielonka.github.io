# Portfolio98 logo

Original emblem generated with the built-in imagegen tool. It combines a terminal,
project folders, code, tools and games in a late-1990s style. The transparent PNG
is used on startup, shutdown and the Start button; the Portfolio98 wordmark stays
as HTML text.

Asset: `src/assets/portfolio98-logo.png` (1448 × 1086, RGBA).

## Generation prompt

```text
Use case: logo-brand.
Create ONE original emblem for Portfolio98, a programmer's interactive portfolio presented inside a CRT monitor with a command-line terminal, retro desktop, folders of web applications, development tools, and small games.
Asset type: production logo symbol replacing a Windows flag above the existing HTML wordmark "Portfolio98" on a late-1990s boot screen. Generate only the emblem, NO wordmark.
Design: one cohesive, bold stacked terminal-and-projects emblem. A slightly forward-tilted dark navy terminal window with a large, unmistakable lime-green ">_" prompt, backed by two offset chunky project cards in cobalt blue and warm amber. A short, sparse trail of square pixels peels away to the left, suggesting code becoming applications and retro games. Keep the silhouette unified and immediately legible at 160 pixels wide.
Style: polished late-1990s computer-software box-art logo, crisp stepped contours, restrained bevels, subtle low-color shading, confident graphic geometry. Not a flat modern app icon, not photorealism. Inspired by the optimism and motion of 1990s OS branding, but a genuinely new terminal/folder-based symbol, NOT the Windows flag, no four-pane window, no Microsoft marks.
Composition: single centered emblem, roughly 4:3 proportions, fills about 88% of the canvas; ample but tight clean transparent border, no clipping, no cast shadow extending outside the symbol. Transparent RGBA background; do not draw a checkerboard, sky, clouds, desktop or mockup.
Palette: near-black/navy edges, cobalt and teal blue, warm amber, lime-green terminal prompt. Strong contrast over a pale cloudy blue background.
Text: only the large terminal prompt ">_"; no words, no letters, no numerals, no watermark.
```
